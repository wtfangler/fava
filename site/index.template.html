03 / LoaderLoader

Własny ekran ładowania zamiast logo Mojang.Its own loading screen instead of the Mojang logo.

Przy starcie gry, przeładowaniu zasobów i zapisywaniu świata widzisz ciemny ekran z logo Fancy Vanilla i cienkim paskiem postępu. Loader jest częścią Fancy Journal, więc nie wymaga osobnego moda. Ładowaniem i wygaszaniem nadal steruje gra, nakładka tylko rysuje na wierzchu; gdyby się nie wczytała, zostaje zwykły ekran vanilli.While the game starts, reloads resources, or saves a world you see a dark screen with the Fancy Vanilla wordmark and a thin progress line. The loader ships inside Fancy Journal, so it is not a separate mod. The game still runs loading and fading; the overlay only draws on top, and if it fails to load you simply get the vanilla screen.

04 / Progresja TEMPEREDTEMPERED progression

Siedem er, nie trzeba zaliczać wszystkiego.Seven ages, you do not need to finish everything.

Era odblokowuje przepisy i sprzęt. Postęp jest wspólny dla świata, także na serwerze. Do następnej ery wystarczy część zadań z obecnej (kolumna „Próg”). Dodatkowe cele są opcjonalne, mają osobny postęp i dają XP, ale nie liczą się do progu.An age unlocks recipes and gear. Progress is shared by the world, also on a server. A part of the current age's quests is enough to advance (the “Threshold” column). Extra goals are optional, personal, give XP, and do not count towards the threshold.

Blokadę przepisów i osłabienia sprzętu wyłącza administrator komendą /function tempered:admin/gate_off. TEMPERED to autorski mod, który zajmuje jeden plik w paczce.An administrator disables the recipe lock and gear penalties with /function tempered:admin/gate_off. TEMPERED is the author's own mod and takes a single file in the pack.

06 / SerwerServer

Ta sama paczka, mały serwer ze znajomymi.The same pack, a small server for friends.

  1. Gracze importują ten sam plik .mrpack co Ty.Players import the same .mrpack you do.
  2. Pobierz skrypt budowy serwera i uruchom go na pliku paczki (Python, Java 25). Skrypt pobiera tylko mody serwerowe i sprawdza ich sumy.Download the server builder and run it on the pack file (Python, Java 25). It downloads only server-side mods and verifies their hashes.
  3. Przeczytaj i zaakceptuj EULA Minecrafta w eula.txt, potem uruchom start.bat lub start.sh.Read and accept the Minecraft EULA in eula.txt, then run start.bat or start.sh.

Ustawienia startowe (15 graczy, zasięg 8, symulacja 6) to wartości początkowe, nie zmierzona pojemność. Zacznij od kilku osób i sprawdź czasy ticków sparkiem.The starting settings (15 players, view distance 8, simulation 6) are defaults, not measured capacity. Start with a few people and check tick times with spark.
